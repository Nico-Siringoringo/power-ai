# AI Web Application

## Overview

This web application is an AI-powered platform that enables users to interact with advanced artificial intelligence through a simple and intuitive interface. It supports text conversations, image generation, and video generation within a single application.

## Features

### 💬 AI Chat

The chat feature allows users to communicate with an AI assistant using natural language.


### 🖼️ Image Generation

Users can generate images by providing a text description (prompt). The AI creates an image based on the user's request.


### 🎥 Video Generation

The application can generate short videos from text prompts.
